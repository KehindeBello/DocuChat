## 🚀 Getting Started

These instructions assume no prior experience setting up the project.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [Git](https://git-scm.com/)
- A package manager: `npm`, `yarn`, or `pnpm`

### 1. Clone the repository

```bash
git clone https://github.com/kehindebello/docuchat.git
cd docuchat
```

### 2. Install dependencies

```bash
npm install
```

### 3. Set up environment variables

Create a `.env` file in the root folder using `.env.example` file as reference

### 4. Run the app

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
